使用 mkdocs-encryptcontent-plugin 加密部分文档
https://github.com/unverbuggt/mkdocs-encryptcontent-plugin


在网站底部添加「免责声明」：
**声明**：本网站收款仅用于个人技术分享支持，不构成任何商业服务。付款行为属于用户自愿捐赠，不代表购买任何商品或服务。

结合 mkdocs-encryptcontent-plugin 实现「付款后查看」逻辑：
用户未付款时，内容加密显示：
---
password: 需要支付后获取
---
用户付款后，通过邮件发送临时密码解锁内容。

直接在 MkDocs 中展示个人收款码是个人项目最快捷的收费方式，尤其适合：
- 技术文档、教程类项目（如付费 API 文档）。
- 开源项目捐赠（如 GitHub Sponsors 替代方案）。
- 低频小额收款（如单次 10~100 元的内容付费）。

关键建议：
- 保持项目小规模、低频次收款，避免触发支付平台风控。
- 优先使用微信 / 支付宝官方收款码，切勿使用第三方聚合收款工具（如易宝、收钱吧）。
- 结合加密插件和人工审核，平衡内容安全与用户体验。
- 这种「简单粗暴」的方式虽缺乏自动化，但胜在零成本、零门槛，非常适合独立开发者快速验证商业想法。
