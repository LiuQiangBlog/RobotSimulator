DSPatch（发音为"dispatch"）是一个强大的 C++数据流框架。
该框架不局限于任何特定领域或数据类型，从响应式编程到流处理，DSPatch 通用的面向对象 API 允许您构建几乎任何能想象到的图处理系统。
